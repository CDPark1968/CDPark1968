**옵시디언 + 노션 + 구글 드라이브** 전반의 지식 그래프 연결성을 강화합니다.

---

## 옵시디언 연결 강화

1. **엔티티 목록화** — 사람, 프로젝트, 고객, 개념 등 링크 가능한 모든 항목 카탈로그
2. **미링크 언급 탐지** — `[[]]` 없이 등장하는 엔티티 검색
3. **양방향 확인** — 링크된 항목의 `## 관련 노트` 섹션에 역링크 존재 여부
4. **고아 분석** — 인링크 0개인 노트에 연결 포인트 제안

---

## 노션 연결 강화 (Notion MCP)

```
mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-search
  query: <엔티티명>
→ 해당 엔티티가 언급된 노션 페이지 탐색
```

점검 항목:
- **미링크 멘션** — 노션 페이지 본문에서 다른 페이지 이름이 텍스트로만 등장 (링크 미연결)
- **데이터베이스 관계 누락** — Relation 속성이 비어있는 항목
- **옵시디언↔노션 교차 참조** — 옵시디언에서 언급된 주제가 노션에 있는데 연결 없음

```
mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-create-comment
  → 연결 강화 제안을 노션 페이지 코멘트로 추가 (승인 후)
```

## 구글 드라이브 교차 참조 (Google Drive MCP)

```
mcp__4e342670-df57-41e4-805d-dcbd06064b06__search_files
  query: <엔티티명 또는 프로젝트명>
→ 관련 드라이브 문서 탐지
```

점검 항목:
- **옵시디언↔드라이브 연결** — 옵시디언 노트에서 언급된 문서가 드라이브에 존재하는데 링크 없음
- **드라이브 파일 메타데이터 확인**
```
mcp__4e342670-df57-41e4-805d-dcbd06064b06__get_file_metadata
  fileId: <파일 ID>
→ 관련 노트에 드라이브 링크 추가 권고
```

```markdown
### 선택 사항 (🟡)
```
