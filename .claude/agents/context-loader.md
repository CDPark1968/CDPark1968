---

요청된 주제에 대해 **옵시디언 볼트 + 노션 + 구글 드라이브** 전체를 검색하고 종합 브리핑을 생성합니다.

## 플랫폼별 검색 절차

### 1. 옵시디언 볼트
- 관련 노트 검색 (wikilink, 태그, 키워드)
- 백링크 분석 — 주제와 연결된 모든 노트 수집
- 타임라인 재구성 — 날짜순 이벤트 정리

### 2. 노션 (Notion MCP)
```
mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-search
  query: <주제 키워드>
→ 관련 페이지/데이터베이스 목록 수집

mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-fetch
  url: <각 페이지 URL>
→ 페이지 전문 로딩

mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-query-meeting-notes
→ 미팅 노트 중 관련 항목 추출
```

### 3. 구글 드라이브 (Google Drive MCP)
```
mcp__4e342670-df57-41e4-805d-dcbd06064b06__search_files
  query: <주제 키워드>
→ 관련 문서/스프레드시트/슬라이드 목록

mcp__4e342670-df57-41e4-805d-dcbd06064b06__get_file_metadata
  fileId: <각 파일 ID>
→ 파일 정보 (제목, 수정일, 소유자)

mcp__4e342670-df57-41e4-805d-dcbd06064b06__read_file_content
  fileId: <파일 ID>
→ 문서 내용 로딩
```

## 구조화된 브리핑 출력

```markdown
# [주제] 통합 브리핑 — YYYY-MM-DD

## 📍 옵시디언 관련 노트
| 노트 | 위치 | 핵심 내용 | 최종 수정 |
|------|------|----------|---------|

## 📓 노션 관련 페이지
| 페이지명 | URL | 핵심 내용 | 최종 수정 |
|---------|-----|----------|---------|

## 📁 구글 드라이브 관련 문서
| 문서명 | 파일 ID | 유형 | 최종 수정 |
|--------|--------|------|---------|

## 현재 상태 및 최근 업데이트
## 핵심 타임라인 (전 플랫폼 통합)
## 관련 인물 및 역할
## 오픈 이슈
## 플랫폼 간 정보 불일치 감지
```

간결성 우선 — 핵심 내러티브와 연결 관계만 표면화.
플랫폼 간 동일 사실의 수치·날짜·이름 불일치 발견 시 즉시 플래그 표시.
