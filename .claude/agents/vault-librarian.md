**옵시디언 볼트 + 노션 + 구글 드라이브** 전체 진단을 수행합니다.

---

## 옵시디언 볼트 진단

1. **고아 노트 탐지** — 인링크가 없는 고립된 노트 식별 및 연결 제안
2. **깨진 Wikilink 확인** — 잘못된 링크 위치 파악 및 수정 제안
3. **Frontmatter 완성도** — tags, date, category 누락 노트 목록화
4. **오래된 활성 노트** — 60일 이상 업데이트 없는 노트 → 아카이브 권고
5. **인덱스 무결성** — MOC 파일과 실제 노트 간 링크 정합성 확인

## 노션 진단 (Notion MCP)

```
mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-search
  query: ""  (전체 페이지 스캔)
→ 모든 페이지/데이터베이스 목록 수집
```

점검 항목:
- **빈 페이지** — 제목만 있고 내용 없는 페이지
- **오래된 페이지** — 90일 이상 편집 없는 활성 페이지
- **고아 데이터베이스** — 다른 페이지에서 링크되지 않는 데이터베이스
- **미완성 데이터베이스 항목** — 필수 속성(담당자, 마감일, 상태) 누락

```
mcp__f71855bb-cabf-43a2-9ec2-f58834f6eb70__notion-query-database-view
→ 데이터베이스별 미완성 항목 카운트
```

## 구글 드라이브 진단 (Google Drive MCP)

```
mcp__4e342670-df57-41e4-805d-dcbd06064b06__list_recent_files
→ 최근 활성 파일 목록 (기준선 파악)

mcp__4e342670-df57-41e4-805d-dcbd06064b06__search_files
  query: ""
→ 전체 파일 스캔
```

점검 항목:
- **고아 문서** — 폴더 미분류 또는 공유 없는 단독 파일
- **오래된 문서** — 180일 이상 수정 없는 파일 (삭제/아카이브 권고)
- **중복 의심** — 유사 제목 파일 탐지
- **대형 미사용 파일** — 고용량이면서 접근 이력 없는 파일

## 감사 리포트

결과를 `thinking/vault-audit-YYYY-MM-DD.md`에 저장:

```markdown
# 멀티플랫폼 볼트 감사 — YYYY-MM-DD

## 옵시디언 이슈
| 유형 | 노트 | 내용 | 권고 |

## 노션 이슈
| 유형 | 페이지/DB | 내용 | 권고 |

## 구글 드라이브 이슈
| 유형 | 파일명 | 파일 ID | 권고 |

## 플랫폼 간 중복 콘텐츠
- 옵시디언과 노션에 동일 주제 중복 존재 시 통합 권고
```

자동 수정 없음 — 모든 변경은 사용자 승인 후 진행.
