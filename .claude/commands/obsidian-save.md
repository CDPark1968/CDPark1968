# Obsidian 노트 저장 스킬

이 스킬이 호출되면 아래 단계를 순서대로 실행하라.

## 1단계 — 내용 파악

현재 대화에서 저장할 핵심 내용을 파악한다:
- 분석·리서치 주제가 무엇인가?
- 핵심 결론과 인사이트는 무엇인가?
- 액션 아이템이 있는가?

## 2단계 — 메타데이터 결정

다음을 자동으로 추론한다:
- **제목**: 대화 주제를 간결하게 (한국어, 30자 이내)
- **태그**: 주제에서 3~5개 자동 추출 (예: 시장분석, 반도체, 투자전략)
- **폴더**: 아래 규칙에 따라 결정

| 내용 유형 | 저장 폴더 |
|-----------|-----------|
| 시장·주식·투자 분석 | `~/obsidian-vault/분석리서치/투자` |
| 비즈니스·전략·마케팅 | `~/obsidian-vault/분석리서치/비즈니스` |
| 기술·개발·AI | `~/obsidian-vault/분석리서치/기술` |
| 기타 리서치 | `~/obsidian-vault/분석리서치/기타` |

## 3단계 — 노트 작성

아래 템플릿을 채운다. 섹션이 비어있으면 해당 섹션을 생략한다.

```
---
created: {{오늘 날짜 YYYY-MM-DD}}
updated: {{오늘 날짜 YYYY-MM-DD}}
type: 분석/리서치
tags:
  - {{태그1}}
  - {{태그2}}
  - {{태그3}}
source: Claude AI
status: 완료
aliases:
  - {{제목 별칭}}
---

# {{제목}}

> **한줄 요약**: {{핵심을 한 문장으로}}

---

---

## ⚠️ 리스크 / 반론

{{존재하는 경우만. 반대 시나리오, 한계, 주의사항}}

*저장일: {{오늘 날짜}} · 출처: Claude AI 대화*
```

## 4단계 — 파일 저장

- **파일명 규칙**: `YYYY-MM-DD_제목.md` (공백은 하이픈으로, 특수문자 제거)
- **예시**: `2026-07-02_SK하이닉스-ADR-시장분석.md`
- **저장 경로**: 2단계에서 결정한 폴더

Bash 도구로 폴더를 먼저 생성한 다음, Write 도구로 파일을 저장한다:

```bash
mkdir -p ~/obsidian-vault/분석리서치/[하위폴더]
```

## 5단계 — 저장 완료 보고

저장 후 다음 형식으로 간결하게 보고한다:

```
✅ Obsidian 저장 완료

📁 경로: ~/obsidian-vault/분석리서치/투자/2026-07-02_제목.md
🏷️ 태그: #시장분석 #투자전략 #반도체
📝 섹션: 개요 · 핵심발견 · 상세분석 · 리스크 · 액션아이템
```

---

## 주의사항

- 저장 전에 파일이 이미 존재하는지 확인하고, 존재하면 덮어쓸지 묻는다.
- 대화 내용이 너무 길면 핵심만 요약하되, 원본 구조(표, 목록, 코드)는 보존한다.
- 날짜는 항상 한국 시간 기준으로 작성한다.
- 태그는 `#` 없이 작성한다 (Obsidian frontmatter 규칙).
