description: Capture freeform notes and file them in the right place
---

자유형식 메모를 캡처하여 볼트의 적절한 위치에 저장합니다.

$ARGUMENTS 내용을 분석하여:

1. 내용 유형 자동 판별:
   - 업무/미팅 관련 → `01_업무/미팅노트/`
   - MPS/키파운드리 전략 → `02_전략/`
   - 투자/재무 생각 → `05_재무투자/`
   - 골프 기록 → `07_골프/`
   - 개인 생각/일기 → `06_개인/`

2. 적절한 파일에 저장 (기존 파일 있으면 추가, 없으면 새로 생성)
3. 오늘 일간 노트에도 링크 추가
4. 저장 위치 보고

사용 예: `/om-dump MPS 미팅에서 Derek이 2027년 45K WSPM 요구한다고 함`
