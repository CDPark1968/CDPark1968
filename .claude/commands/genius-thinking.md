# 천재적 사고 공식화 (Genius Thinking Formula)

사용자의 질문, 아이디어, 또는 정보를 받으면 아래 절차를 따르세요.

**입력**: $ARGUMENTS

---

## 실행 절차

### STEP 1 — 사고법 선택 및 혼합 분석 (1500자 이상)

아래 10가지 공식 중 입력된 주제에 가장 적합한 **2가지를 선택**하여 혼합 적용하세요.  
선택 이유를 먼저 밝히고, 두 공식을 교차 적용하여 심층 분석을 수행합니다.

---

#### 공식 1. 천재적 통찰 도출 공식 (Genius Insight Formula)
**GI = (O × C × P × S) / (A + B)**
- O(Observation) = 관찰의 깊이
- C(Connection) = 연결의 독창성
- P(Pattern) = 패턴 인식 능력
- S(Synthesis) = 종합적 사고
- A(Assumption) = 고정관념 수준 (낮을수록 좋음)
- B(Bias) = 편향 정도 (낮을수록 좋음)

각 요소에 1–10점을 부여하고, 관찰→연결→패턴→종합 순으로 사고를 전개합니다.

---

#### 공식 2. 다차원적 분석 프레임워크
**MDA = Σ[Di × Wi × Ii]**
- D1 = 시간적 차원 (과거-현재-미래)
- D2 = 공간적 차원 (로컬-글로벌-우주적)
- D3 = 추상적 차원 (구체-중간-추상)
- D4 = 인과적 차원 (원인-과정-결과)
- D5 = 계층적 차원 (미시-중간-거시)

각 차원의 가중치(Wi)와 영향력(Ii)을 평가하여 다각도 분석을 수행합니다.

---

#### 공식 3. 창의적 연결 매트릭스
**CC = |A ∩ B| + |A ⊕ B| + f(A→B)**
- A ∩ B = 공통 요소
- A ⊕ B = 배타적 차이 요소
- f(A→B) = 전이 함수

연결 탐색 순서: 직접적 → 간접적 → 역설적 → 메타포적 → 시스템적

---

#### 공식 4. 문제 재정의 알고리즘
**PR = P₀ × T(θ) × S(φ) × M(ψ)**
- T(θ) = 관점 회전 (θ = 180°: 반대 관점)
- S(φ) = 범위 조정 (φ = 0.1x ~ 10x)
- M(ψ) = 메타 레벨 이동 (ψ = ±1,±2,±3)

---

#### 공식 5. 혁신적 솔루션 생성 공식
**IS = Σ[Ci × Ni × Fi × Vi] / Ri**
- Ci = 조합 방식, Ni = 참신성, Fi = 실현가능성
- Vi = 가치 창출, Ri = 위험 요소

---

#### 공식 6. 인사이트 증폭 공식
**IA = I₀ × (1 + r)ⁿ × C × Q**
- I₀ = 초기 인사이트, r = 개선율, n = 반복 횟수
- C = 협력 효과(1–3배), Q = 질문의 질(1–5배)

증폭 전략: Why × 5회 이상, What if 시나리오, How might we 질문

---

#### 공식 7. 사고의 진화 방정식
**TE = T₀ + ∫[L(t) + E(t) + R(t)]dt**
- L(t) = 학습 함수, E(t) = 경험 축적, R(t) = 반성적 사고

---

#### 공식 8. 복잡성 해결 매트릭스
**CS = det|M| × Σ[Si/Ci] × ∏[Ii]**
- 시스템 분해 → 관계 매핑 → 레버리지 포인트 식별 → 최적화

---

#### 공식 9. 직관적 도약 공식
**IL = (S × E × T) / (L × R)**
- S = 정적 사고 시간, E = 경험, T = 직관 신뢰
- L = 논리적 제약(낮을수록 좋음), R = 과도한 합리화(낮을수록 좋음)

---

#### 공식 10. 통합적 지혜 공식
**IW = (K + U + W + C + A) × H × E**
- K = 지식, U = 이해, W = 지혜, C = 공감
- A = 실행력, H = 겸손, E = 윤리

---

### STEP 2 — 천재적 아이디어 10개 이상 출력 (3000자 이상)

STEP 1의 분석을 기반으로 **창의적이고 실행 가능한 천재적 아이디어 10개 이상**을 제시하세요.

각 아이디어는 다음 형식으로 작성합니다:
```
### 아이디어 N: [제목]
- **핵심 개념**: 
- **적용 공식**: (선택한 공식 번호)
- **구체적 실행 방안**: 
- **기대 임팩트**: 
- **혁신 포인트**: 
```

---

## 사용 가이드라인
1. 각 공식을 기계적으로 따르지 말고 창의적으로 변형하여 사용
2. 분석적 사고와 직관적 사고를 균형 있게 활용
3. 아이디어는 구체적이고 실행 가능하게 제시
4. 고정관념을 깨고 다양한 도메인을 교차 연결
