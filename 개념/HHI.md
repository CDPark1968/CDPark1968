# HHI — Herfindahl-Hirschman Index (허핀달-허쉬만 지수)

## 정의

> 시장 집중도를 측정하는 지수. 각 참여자의 시장점유율 제곱의 합.
> 파운드리 맥락에서는 **고객 매출 집중도**를 나타낸다.

## 해석 기준

| HHI 범위 | 의미 |
|---------|------|
| < 1,000 | 분산 (양호) |
| 1,000 ~ 1,800 | 중간 집중 (주의) |
| > 1,800 | 고집중 (위험) |
| **~2,000** | [[02_전략/키파운드리|SKKF]] 현재 → **🔴 위험** |

## SKKF 현황

- 현재 [[개념/HHI|HHI]] ≈ 2,000 → 권고 기준(1,000) 2배 초과
- [[02_전략/MPS|MPS]] 단일 고객 비중 54%가 주요 원인
- 목표: 2027년까지 HHI 1,000 이하로 하락 (Shadow Pipeline 통한 고객 다변화)
