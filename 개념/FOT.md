# FOT — Full Out Target (최대 가동 목표)

## 정의

> Fab이 특정 고객에게 최대로 공급할 수 있는 물량 목표치.
> 현재 [[02_전략/MPS|MPS]] FOT = 16K wpm → **60% 달성 목표**.

## SKKF FOT 구조

| 항목 | 수치 |
|------|------|
| MPS FOT | 16K wpm |
| 달성 목표 | 60% |
| 현재 base capa | 30K wpm |
| Ceiling | 35K wpm |
| 전체 fab capa | 85K~95K wpm |

## 의미

- FOT 달성률이 높을수록 가동률 개선 → [[개념/OPM|OPM]] 향상
- 증설 시 FOT 상향 조정 논리로 활용
- [[개념/LTA|LTA]]와 연계: 물량 Commit → FOT 보장
