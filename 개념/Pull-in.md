# Pull-in 프리미엄 정책

## 정의

> 고객이 원래 납기보다 **앞당겨** 물량을 받고자 할 때 부과하는 프리미엄 요금제.
> 공급자(SKKF)의 단가 협상력을 강화하는 레버리지 수단.

## 전략적 의미

| 관점 | 내용 |
|------|------|
| 수익성 | 일반 단가 대비 프리미엄 → [[개념/OPM|OPM]] 개선 |
| 협상력 | 고객이 필요한 시점에 공급력 = 레버리지 |
| 고객 관계 | 긴급 수요 해결 → 관계 강화 |
