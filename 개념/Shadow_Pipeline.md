# Shadow Pipeline (잠재 고객 파이프라인)

## 정의

> [[02_전략/MPS|MPS]] 외 대체 고객을 조용히 육성하는 전략적 영업 파이프라인.
> "Shadow"는 공개하지 않고 병행 운영한다는 의미 — MPS와의 협상 레버리지 확보.

## 전략적 역할

| 기능 | 설명 |
|------|------|
| 협상 레버리지 | MPS에 "다른 옵션 있음"을 암시 → 조건 개선 |
| HHI 완화 | 신규 고객 매출 확대 → [[개념/HHI|HHI]] 하락 |
| 리스크 분산 | MPS 이탈 시 대체 수요 확보 |

## 현황 및 목표

- 현재: 미구축 상태 (구조적 전략으로만 언급)
- **목표**: 2027년 MPS 비중 54% → 45% 이하
- **방법**: Tier-1 신규 고객 3개사 집중 공략, FAE 전담 배치

## 타겟 기준

```
□ Tier-1 글로벌 팹리스 또는 IDM
□ BCD / Power MOSFET 계열 제품
□ SKKF 공정과 매칭 가능한 기술 스펙
```
