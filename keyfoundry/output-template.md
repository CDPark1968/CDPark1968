# 키파운드리 GSM AI Agent 산출물 출력 템플릿

`/keyfoundry-debate` 세션 및 개별 GSM Agent가 CEO 보고용 산출물을 작성할 때 아래 구조를 따른다.

```markdown
# <안건명>

## 결론 (3줄)
1.
2.
3.

## Conflict Log
| 쟁점 | Agent A 주장 | Agent B 주장 | 충돌지점 | 중재(총괄) |
|---|---|---|---|---|
|  |  |  |  |  |

## 통합 권고안
-

## 놓치고 있던 관점 (사고 확장)
-

## 리스크
-

## Decision Ask
- [ ] 승인 / [ ] 보류 / [ ] 재검토

---
*Origin: Codex (Claude Code) · <YYYY-MM-DD>*
```

## 표기 규칙
- `<YYYY-MM-DD>`는 산출물을 실제로 생성한 날짜로 채운다(템플릿 자체에 고정 날짜를 넣지 않는다).
- "Origin: Codex (Claude Code)" 표기는 노션 저장본과 Obsidian 요약본 모두에 동일하게 남긴다.
- Notion에 저장할 때는 페이지 최상단(Callout 또는 인용구)에도 동일한 Origin/Date 한 줄을 반복한다.
